┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. КОНФИГУРАЦИЯ ТРЕКБОЛА                                                    │
└─────────────────────────────────────────────────────────────────────────────┘

✅ Добавлены продвинутые слушатели ввода:
   • trackball_listener - auto-mouse layer (TTL 1000ms)
   • trackball_snipe_listener - precision mode (делитель 1/3)
   • trackball_scroll_listener - scroll mode (всенаправленная прокрутка)
   • ib_wheel_scaler - масштабирование колеса
   • ib_toggle_layer - автоматическое переключение слоев

✅ Три режима работы трекбола:
   • Cursor Mode - обычный курсор с авто-активацией MOUSE слоя
   • Precision Mode - медленный курсор для точности (×0.33)
   • Scroll Mode - прокрутка во всех направлениях

┌─────────────────────────────────────────────────────────────────────────────┐
│ 2. BEHAVIORS И МАКРОСЫ                                                      │
└─────────────────────────────────────────────────────────────────────────────┘

✅ Home Row Mods с оптимизированными параметрами:
   • hml/hmr - основные (tapping-term: 2000ms, idle: 250ms)
   • hml_s/hmr_s - варианты с instant idle
   • Левая: A(GUI), S(ALT), D(CTRL), F(SHIFT)
   • Правая: J(SHIFT), K(CTRL), L(ALT), ;(GUI)

✅ Дополнительные behaviors:
   • scrl_clk - hold-tap для scroll/click
   • smart_shift - mod-morph для Shift/Caps Word

✅ Макросы:
   • lang - переключение языка (Win+Space)
   • screenshoot - скриншот (Ctrl+Shift+Print)

┌─────────────────────────────────────────────────────────────────────────────┐
│ 3. COMBOS (30+)                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

✅ Адаптированы все позиции для 4×6 матрицы:
   • Клики мыши (обе руки, thumb cluster)
   • Навигация (ESC, TAB, DELETE, ENTER, Space, Grave)
   • Символы (скобки, операторы, минус, плюс)
   • Управление слоями (MOUSE, FUNCTION, GAME, RESET, BASE)
   • Системные (unlock, bootloader)
   • Кнопки мыши (Forward, Back)

┌─────────────────────────────────────────────────────────────────────────────┐
│ 4. РАСКЛАДКА КЛАВИШ (7 слоев)                                              │
└─────────────────────────────────────────────────────────────────────────────┘

✅ BASE (0) - QWERTY + Home Row Mods
✅ MOUSE (1) - модификаторы + кнопки мыши + sys_reset/bootloader
✅ NUMBER (2) - F1-F12 + навигация + numpad + макросы
✅ SYMBOL (3) - все символы программирования
✅ FUNCTION (4) - scroll mode для трекбола
✅ GAME (5) - игровая заготовка
✅ RESET (6) - технический слой
