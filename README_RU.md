## 🎮 Режимы работы трекбола

### 1. Cursor Mode (курсор) — по умолчанию
При движении трекбола автоматически активируется слой MOUSE на 1 секунду.  
**Где**: BASE, MOUSE, SYMBOL, GAME, RESET слои

### 2. Precision Mode (точность)
Медленный, точный курсор для позиционирования.  
**Как активировать**: удерживать слой NUMBER

### 3. Scroll Mode (прокрутка)
Прокрутка контента во все стороны трекболом.  
**Как активировать**: удерживать слой FUNCTION

## ⌨️ Home Row Mods

**Левая рука:**  
- A = GUI (Win/Cmd)  
- S = ALT  
- D = CTRL  
- F = SHIFT  

**Правая рука:**  
- J = SHIFT  
- K = CTRL  
- L = ALT  
- ; = GUI (Win/Cmd)  

> Модификаторы активируются при **удержании** клавиш, обычное нажатие печатает букву.

## 🐛 Частые вопросы

### Половины не соединяются?
1. Нажмите reset на обеих половинах одновременно
2. Прошейте settings_reset firmware

### Трекбол не работает?
1. Проверьте, что прошили правую половину (с трекболом)
2. Проверьте CPI в `charybdis_3610.dtsi`

### Home Row Mods срабатывают случайно?
Увеличьте `require-prior-idle-ms` до 300-400 в `charybdis.keymap`

**Подробнее:** [QUICK_START.md → Устранение неполадок](QUICK_START.md#устранение-неполадок)
