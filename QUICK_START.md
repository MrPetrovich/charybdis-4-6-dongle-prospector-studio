# Быстрый старт - Новая конфигурация

## Что изменилось

✅ **Продвинутая конфигурация трекбола**
- Автоматический переход на слой мыши при движении трекбола
- Режим точности (precision mode) на слое NUMBER
- Режим прокрутки (scroll mode) на слое FUNCTION

✅ **Улучшенные Home Row Mods**
- Левая рука: A(GUI), S(ALT), D(CTRL), F(SHIFT)
- Правая рука: J(SHIFT), K(CTRL), L(ALT), ;(GUI)

✅ **Новые макросы**
- Переключение языка: макрос `lang` (Win+Space)
- Скриншот: макрос `screenshoot` (Ctrl+Shift+Print)

✅ **Расширенные комбинации клавиш (combos)**
- Быстрые клики мыши через комбо на обеих руках
- Навигационные комбо (ESC, TAB, DELETE, ENTER)
- Символьные комбо (скобки, операторы)

## Режимы работы трекбола

### 1. Курсор (по умолчанию)
- **Слои**: BASE, MOUSE, SYMBOL, GAME, RESET
- **Скорость**: делитель 1/2
- **Авто-слой**: при движении автоматически активируется MOUSE на 1 секунду

### 2. Точность (Precision)
- **Активация**: удерживать слой NUMBER (thumb key)
- **Скорость**: делитель 1/3 (медленнее для точного позиционирования)

### 3. Прокрутка (Scroll)
- **Активация**: удерживать слой FUNCTION (thumb key)
- **Направление**: всенаправленная прокрутка
- **Y-инверсия**: включена

## Основные слои

### BASE (0)
Базовая QWERTY раскладка с Home Row Mods

### MOUSE (1)
- Левая рука: модификаторы (GUI, ALT, SHIFT, CTRL)
- Правая рука: кнопки мыши (MB1, MB2, MB3)
- Thumb: scrl_clk для scroll/click
- Верхний ряд: Sys Reset, Bootloader

### NUMBER (2)
- F1-F12 функциональные клавиши
- Навигация: стрелки, Home, End, Page Up/Down
- Numpad на правой стороне
- Макросы: screenshoot, lang

### SYMBOL (3)
- Специальные символы и операторы
- Скобки всех типов: (), [], {}
- Математические операторы

### FUNCTION (4)
- Scroll mode для трекбола
- Возврат на BASE

### GAME (5)
- Игровой слой (настроить под себя)

### RESET (6)
- Технический слой для сброса настроек

## Полезные комбинации (Combos)

### Клики мыши
- **Левый клик**: thumb+thumb (обе руки)
- **Правый клик**: thumb+thumb (обе руки, другие позиции)
- **Средний клик**: 3 thumb клавиши

### Навигация
- **ESC**: Q+W (1+2)
- **TAB**: W+E (2+3)
- **Ctrl+Backspace**: позиции 11+12
- **Grave**: Q+1 или Q+Tab

### Управление слоями
- **FUNCTION**: 27+28
- **GAME**: 5+9
- **RESET**: 24+28 (левая) или 27+31 (правая)
- **BASE**: 7+8 (возврат)

### Системные
- **ZMK Studio unlock**: 0+4
- **Bootloader**: 34+35 (удерживать 2 секунды)

## Первый запуск

1. **Соберите прошивку** через GitHub Actions
2. **Скачайте артефакты** (требуется авторизация)
3. **Прошейте обе половины**:
   - Дважды нажмите reset на контроллере
   - Скопируйте соответствующий `.uf2` файл
   - Повторите для второй половины
4. **Протестируйте слои**:
   - Проверьте базовый слой и Home Row Mods
   - Проверьте автоматический слой мыши
   - Протестируйте режимы трекбола (cursor/precision/scroll)
   - Проверьте combos

## Тонкая настройка

### Изменить чувствительность трекбола
Отредактируйте `boards/shields/charybdis/charybdis_3610.dtsi`:
```c
&pmw3610 {
    cpi = <800>;  // Измените значение (200-3200)
};
```

### Настроить тайминги Home Row Mods
В `config/charybdis.keymap`, секция `behaviors`:
```c
hml: hml {
    tapping-term-ms = <2000>;      // Время удержания
    quick-tap-ms = <175>;           // Быстрое нажатие
    require-prior-idle-ms = <250>;  // Задержка перед активацией
};
```

### Изменить время жизни авто-слоя мыши
В `config/charybdis.keymap`:
```c
ib_toggle_layer: ib_toggle_layer {
    time-to-live-ms = <1000>;  // Измените на нужное значение (мс)
};
```

## Устранение неполадок

### Трекбол не двигает курсор
1. Проверьте, что прошивка собрана для правой половины (с трекболом)
2. Проверьте подключение сенсора PMW3610
3. Проверьте CPI настройки в device tree

### Home Row Mods срабатывают случайно
1. Увеличьте `require-prior-idle-md` в behaviors
2. Увеличьте `tapping-term-ms`
3. Проверьте `hold-trigger-key-positions`

### Половины не соединяются
1. Нажмите reset на обеих половинах одновременно
2. Прошейте settings reset firmware
3. См. [ZMK Troubleshooting](https://zmk.dev/docs/troubleshooting/connection-issues)

### Combos не работают
1. Проверьте `timeout-ms` и `require-prior-idle-ms` в combos
2. Убедитесь, что позиции клавиш соответствуют вашей раскладке
3. Проверьте, не конфликтуют ли combos между собой
