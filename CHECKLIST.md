## 🔧 Настройки трекбола

### Текущие параметры
```c
// В charybdis_3610.dtsi
cpi = <800>;  // Чувствительность (200-3200)

// В charybdis.keymap
trackball_listener:
  scale-divisor = <2>;  // Cursor mode: ×0.5

trackball_snipe_listener:
  scale-divisor = <3>;  // Precision mode: ×0.33

trackball_scroll_listener:
  scale-divisor = <3>;  // Scroll mode: ×0.33
  y-invert;             // Естественная прокрутка
```

### Рекомендуемые значения CPI
- [ ] 400 - медленный, точный
- [ ] 600 - умеренный
- [x] 800 - сбалансированный (текущее)
- [ ] 1200 - быстрый
- [ ] 1600+ - очень быстрый

## 🔧 Возможные проблемы

### Половины не соединяются
```bash
# Решение:
1. Прошить settings_reset на обе половины
2. Нажать reset на обеих одновременно
3. Дождаться повторного соединения
```

### Трекбол не работает
```bash
# Проверить:
- Прошивка правой половины (с трекболом)
- Подключение сенсора PMW3610
- CPI настройки в charybdis_3610.dtsi
```

### Home Row Mods срабатывают случайно
```bash
# Настроить в config/charybdis.keymap:
hml/hmr {
  require-prior-idle-ms = <250>;  // Увеличить до 300-400
  tapping-term-ms = <2000>;       // Можно уменьшить до 1500
}
```

### Combos не работают
```bash
# Проверить:
- Позиции клавиш соответствуют вашей физической раскладке
- timeout-ms достаточный (20ms)
- require-prior-idle-ms не слишком большой (250ms)
```
